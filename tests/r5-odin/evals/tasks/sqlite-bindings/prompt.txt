Implement query_people and count_rows in sqlite/sqlite.odin using the system SQLite3 library (foreign import "system:sqlite3"; bind the C functions you need yourself in that file). query_people opens an in-memory database, runs setup_sql, runs select_sql, and returns one Row per result row (id from column 0, name from column 1) with each name copied into memory from the given allocator. It frees everything else it allocates. It returns .Exec_Failed if setup_sql fails and .Prepare_Failed if select_sql is invalid, with nothing left allocated. count_rows does the same setup and counts the rows of select_sql using sqlite3_exec with a callback. Make `odin test sqlite` pass. Work only inside the current directory.
