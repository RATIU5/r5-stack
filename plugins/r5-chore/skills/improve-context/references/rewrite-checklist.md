# Rewrite checklist

Limits: see "Size limits" in SKILL.md.

- Imperative and specific. No "usually" or "should".
- Commands in copy-paste code blocks, verified against the repo.
- Critical rules first.
- One fact in one place. Link instead of repeating.
- Examples only when they prevent an error.
- MUST and NEVER only for true invariants.
- No filler, tutorials, history, or anything an LLM finds by reading the repo.
- Define or drop jargon.
- Every path, command and version still exists.
- Always-loaded docs hold only what every task needs. Everything else is on-demand, linked from the root doc.
