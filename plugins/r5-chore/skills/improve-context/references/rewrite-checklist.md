# Rewrite checklist

- Imperative and specific. No "usually" or "should".
- Commands in copy-paste code blocks, verified against the repo.
- Critical rules first.
- One fact in one place. Link instead of repeating.
- Examples only when they prevent an error.
- MUST and NEVER only for true invariants.
- No filler, no tutorials, no history, nothing an LLM finds by reading the repo.
- Clear terms: define or drop jargon.
- Every path, command and version still exists.
- Under 150 lines and 16,000 characters. Split by topic, link from the root doc. Never shrink by being cryptic.
- Always-loaded docs hold only what every task needs. Everything else is on-demand.
